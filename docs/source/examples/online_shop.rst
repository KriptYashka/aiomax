Online shop
===========

Пример «онлайн-магазина» с меню на callback-кнопках: каталог, корзина, контакты.

Запуск:

- ``python -m examples.online_shop.main``

Сценарий:

- отправьте любое сообщение боту → получите главное меню
- нажимайте кнопки меню → бот будет отвечать и показывать следующие клавиатуры
