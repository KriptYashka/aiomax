Getting started
===============

Установка
---------

Проект не содержит закреплённого менеджера зависимостей. Минимально для запуска примеров
нужны:

- Python 3.10+
- ``aiohttp``
- ``python-dotenv`` (для загрузки ``.env``)

Запуск примеров
--------------

1. Создайте ``.env`` в корне проекта и добавьте токен:

   - ``TOKEN=...``
   - (опционально) ``HTTP_PROXY=...``

2. Запустите пример:

   - ``python -m examples.hello_world.main``
   - ``python -m examples.online_shop.main``
